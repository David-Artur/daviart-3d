# daviart-3d
Данные 3D-карты (BlueMap 5.16, статичные плитки) сервера DaviArt Craft для страницы https://daviart.com/3d/.
Генерируются автоматически (minecraft-server/map-render/bluemap), история не хранится — не правьте руками.
Плитки `*.prbm.gz` распаковывает в браузере Service Worker страницы (`/3d/bm-sw.js`).
